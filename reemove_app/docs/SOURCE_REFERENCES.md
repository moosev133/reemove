# Primary Reference Sources

The Phase 15 plan is aligned with these primary sources:

- Flutter testing overview and `integration_test` guidance
- Flutter integration performance profiling guidance
- Firebase Local Emulator Suite and Security Rules unit testing guidance
- Firebase App Check metrics and enforcement guidance
- Firebase Performance Monitoring for Flutter and custom traces
- Firebase Test Lab Flutter integration testing guidance
- OWASP MASVS and MASTG for mobile security verification/testing
- W3C WCAG 2.2 for accessibility principles
- GitHub Actions secure-use guidance

Review current official documentation during Phase 16 before pinning final dependency versions or changing enforcement/production settings.
