## Feature slice convention

```text
features/<feature>/
├── data/
│   ├── data_sources/
│   ├── dto/
│   ├── mappers/
│   └── repositories/
├── domain/
│   ├── entities/
│   ├── repositories/
│   └── value_objects/
├── application/
│   ├── controllers/
│   ├── providers/
│   └── use_cases/
└── presentation/
    ├── screens/
    └── widgets/
```

Dependencies flow inward. Domain code imports neither Flutter nor Firebase. Data implementations may import Firebase. Presentation code reads application providers and never reads Firestore directly.
