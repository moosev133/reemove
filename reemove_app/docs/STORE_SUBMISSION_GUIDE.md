# Store Submission Guide

## Shared assets

- App name and subtitle/short description
- Localized full description: English, Arabic, Hebrew
- App icon and screenshots captured from final production-like builds
- Support URL, privacy policy URL, Terms URL, Community Guidelines URL, account deletion URL
- Contact details monitored during review
- Reviewer credentials and walkthrough
- Version notes with user-visible changes only

## Screenshot coverage

Show real product value rather than empty dashboards:

1. Personalized sports feed
2. Discover and nearby sports experiences without exposing private location
3. Football, gym, and running hubs
4. Challenges and leaderboards
5. Messaging/groups
6. Marketplace
7. AI coach/workout/challenge features with safety-aware copy
8. Profile and privacy controls

Create separate RTL screenshots for Arabic/Hebrew where the store listing is localized.

## Review notes

Explain:

- How reviewers access all roles/features
- Why location, camera, photos, notifications, or other permissions are requested
- How users report/block content and delete accounts
- Which AI features are informational and how unsafe outputs are moderated
- How marketplace transactions are arranged and whether payments occur outside the app
- Any demo data or test-mode limitations

## Release controls

Do not use a forced minimum version until the replacement version is approved and broadly available. Maintenance mode must provide a support path and should be reserved for severe incidents.
